\chapter{Introduction}
In October 2021, Wordle was released and was a resounding success almost immediately after launch. The website grew traction quickly, going from only 90 players on November 1st to 300,000 on January 2nd 2022. This success led to other developers working on games inspired by Wordle and has created a thriving community of smaller websites that follow in what I will refer to as the daily game genre of web application. The daily game genre has had continued success, but only a fraction of what Wordle has received. Josh Wardle, the creator of Wordle, attributes much of the success of Wordle to the outreach of its shareable ‘emoji grid’  that was popular on Twitter early on in Wordle's conception. This was pivotal to bringing users to the website (which has since been acquired by NYT Games and added to their selection). However, once they gained this considerable player base, no functionality made players want to continue; the only thing that drew them back to the website was the game itself. 

My project hypothesises that if we add the retention techniques found in other multiplayer online games to the daily game genre of web applications, users will be more satisfied and will retain more users. Depending on whether my hypothesis is valid, this can be used as an example for other web applications in the daily game genre to add to their websites to make the daily game genre more fun and exciting for users like myself, who play these games daily. 

To test this paper's hypothesis, there will be a self-conducted study of the effectiveness of these retention techniques by creating a simple Wordle clone and a version of Wordle that has the retention techniques of more features, a leaderboard, and a set of achievements for participants to play. They will be asked to complete multiple surveys, and with their permission, the web application will track the activity on their web page to see if there is any increase in time spent. The user will be asked to complete a survey when the testing is over to determine if the participant felt more satisfied using the website with increased functionality.
